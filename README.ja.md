# i18n Translator — Figmaの多言語レイアウト事前チェック（Figma Design Agent 用）

> *English README: see [README.md](README.md).*

Figmaの FRAME / SECTION を選択して実行すると、そのフレームを対象言語ごとに複製し、`INSTANCE`内も含めた全テキストノードを翻訳する — Figma の Design Agent のカスタムスキル機能に登録して利用するスキルです。

**位置づけ:** 本番の多言語実装（実際の翻訳文・i18nルーティング）はコード側で行う前提です。このスキルは、実装前の段階でデザイナー自身が「翻訳した時に文字数の増減でレイアウトが崩れないか」を確認するための、実装前チェック用途を想定しています。翻訳はAIによる自動翻訳のため、そのまま本番の文言として使うのではなく、各言語ネイティブスピーカーによるチェックを経てからコード実装に進むことを推奨します。

> **有料講座について**: このスキルは有料講座「[KMRVID Figma Skills](https://kmrvid-claude-skills.gaspanik.workers.dev/figma/)」に収録されている21スキルの1つと同一内容です（機能を削った軽量版ではありません）。全スキルカタログはこちら: [KMRVID Figma Skills README](https://fragrant-edam-563.notion.site/KMRVID-Figma-Skills-README-md-3ad5dae25dd280d69c12c69b277d90b6)

> **有料講座のプレビュー**: 講座内の各種スキルを実際に動かしている様子は、こちらの[YouTube](https://www.youtube.com/@kmrvid/videos)や講座の[無料プレビュー](https://kmrvid.com/apps/ldt-course/course/6922c0ad336ff5545bbff61d/6a6b17c49dc4e0183716f605?locale=ja)（アカウント作成、ログイン不要）に掲載しております。

## これは何か

本番の多言語実装（実際の翻訳・i18nルーティング）はコードで行うものですが、コードレビューの段階では気づきにくいのが「レイアウトそのものが翻訳後も崩れないか」という点です。ドイツ語の見出しは長くなりがちで、日本語の文章は詰まって見え、英語なら3行に収まっていたカードが、言語が変わった途端にはみ出したり、崩れた折り返しになったりします。

このスキルは、それをコードを書く前の段階でキャンバス上に可視化します。出荷予定の言語にフレームを複製し、レイアウトが持ちこたえるかその場で確認してから、どのセクションにオートレイアウトの手当てが必要かを把握した上で実装に進めます。

```
キャンバス上でFRAME/SECTIONを選択
        │
        ▼
Walk tree via Plugin API, don't skip INSTANCE subtrees
        │
        ▼
元言語を自動判定 → 複製先の言語を質問
        │
        ▼
オートレイアウト未設定なら警告（文字数変化でレイアウトが崩れる可能性）
        │
        ▼
全テキストノードを翻訳し、言語ごとにプレビュー表を提示
        │
        ▼
複製・適用: clone→翻訳→text-wrap style/均等揃えを自動調整
        │
        ▼
サンプル検証後、適用/スキップ件数と目視確認のリマインドをレポート
```

`INSTANCE`のサブツリーはスキップしません — ボタンラベルやカードタイトルなど、コンポーネントインスタンス内にある実際に見えるコピーこそ、このスキルが確認したい対象だからです。

Figmaの新しいプロパティ`textWrapStyle`（見出し系はBALANCE、本文はPRETTY）も翻訳後の各ノードに自動設定し、孤立語や不揃いな見出しをあらかじめ軽減します。

## スコープ

- **実際にファイルへ書き込みます。** 読み取り専用のプレビューではなく、フレームを複製してPlugin API経由で翻訳文を実際に適用します。元のフレームには一切手を加えません
- **対象ノード種別:** `FRAME`または`SECTION`のみ
- **対応言語:** English / Spanish / French / German / Portuguese / Chinese (Simplified) / Japanese / Korean のプリセット、および自由記述言語
- **非対応:** レイアウト崩れの自動修正（修正はせず警告のみ）、数値・日付・通貨のロケール別フォーマット変換、右横書き言語（アラビア語・ヘブライ語等、現時点ではスコープ外）
- **翻訳の精度について:** 翻訳文はAI生成です。レイアウト確認用の下書きとして扱い、そのまま本番の文言とはせず、各言語のネイティブスピーカーによるチェックを経てから公開してください

**なぜレイアウト崩れを自動修正しないのか:** 翻訳後の文字数変化でレイアウトが綺麗に追従するかどうかは、そのフレームがどう作られているか（オートレイアウト＋適切なサイジング設定か、固定サイズか）に完全に依存しており、このスキルが安全に推測して修正できるものではありません。不用意な修正はデザインの意図しない構造変更を招くリスクがあります。代わりに、複製前にオートレイアウト未設定を警告し、複製後は目視確認をリマインドします。リスクを可視化することがこのツールの役割であり、覆い隠すことではありません。

**2. キャンバス上で対象のFRAMEまたはSECTIONを選択**

```
Duplicate this frame in Spanish and Korean so I can check the layout
```

大きなフレーム（テキストノード60個以上）は処理に少し時間がかかりますが、通常の動作です。

## 実行時の流れ

1. **対象の確認** — キャンバス上の選択がFRAME/SECTIONかどうかを確認
2. **テキストノードの走査** — ツリー全体（インスタンス内含む）から全テキストノードを収集し、元言語を自動判定
3. **複製先言語の確認** — プリセット8言語＋自由記述から選択
4. **オートレイアウト確認** — 未設定の場合は続行確認、設定済みなら静かに進行
5. **翻訳とプレビュー** — 言語ごとに翻訳プレビュー表を提示し、適用前に明示的な確認を取る
6. **複製・適用** — フレームを複製し、翻訳文とtext-wrap style・均等揃えの調整を適用
7. **検証とレポート** — サンプル検証後、適用/スキップ件数と目視確認のリマインドを出力
